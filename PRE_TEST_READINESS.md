# Pre-Test Readiness

## Application

- [ ] Frontend starts successfully.
- [ ] Backend starts successfully.
- [ ] API health endpoint works.
- [ ] Database / knowledge store is reachable.
- [ ] Seed data loads correctly.

## Core demo

- [ ] User can enter a query.
- [ ] Query normalization is visible or traceable.
- [ ] Relevant candidates are returned.
- [ ] Ranking is deterministic enough for the demo.
- [ ] Evidence/provenance is displayed.
- [ ] Safety messaging is displayed.

## Reliability

- [ ] Empty input handled.
- [ ] Unknown terminology handled.
- [ ] No-result state handled.
- [ ] Backend failure handled.
- [ ] Invalid data rejected.

## Presentation

- [ ] 60-second problem explanation.
- [ ] 90-second architecture explanation.
- [ ] 2-minute live demo.
- [ ] 30-second impact statement.
- [ ] Backup screenshots/video available.

## Repository

- [ ] README is complete.
- [ ] Architecture diagram renders.
- [ ] Setup instructions are accurate.
- [ ] No secrets committed.
