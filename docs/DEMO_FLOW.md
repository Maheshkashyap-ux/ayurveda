# Hackathon Demo Flow

## 1. Opening

State the problem in one or two sentences.

## 2. Input

Enter one prepared natural-language query.

## 3. Show normalization

Briefly show how the system interprets the query.

## 4. Show retrieval

Display relevant candidates.

## 5. Show ranking explanation

Explain why the leading result appears near the top.

## 6. Show evidence

Open the source/provenance section.

## 7. Show safety

Point out the responsible-use and limitation layer.

## 8. Close

Summarize the technical differentiation:

```text
Natural language
      ↓
Normalization
      ↓
Hybrid retrieval
      ↓
Ranking
      ↓
Evidence
      ↓
Explainable result
```

Prepare screenshots/video as a backup for network or deployment failure.
