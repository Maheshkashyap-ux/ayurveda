# Provenance and Evidence

## Why provenance matters

A recommendation-like result is more trustworthy when the user can inspect where the underlying information came from.

## Evidence record

A useful evidence object can contain:

```text
evidence_id
entity_id
source
citation
source_type
access_date
evidence_status
notes
```

## Presentation

The UI should distinguish:
- source-backed information
- curated mappings
- system-generated ranking
- unsupported / unavailable information

## Rule

Do not imply that a source proves more than it actually supports.
