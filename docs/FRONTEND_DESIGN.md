# Frontend Design

## Primary screens

### 1. Home / Search
Clear entry point with a natural-language search box.

### 2. Results
Display ranked candidates with concise explanations.

### 3. Detail
Show formulation/ingredient information, relationships, provenance, and limitations.

### 4. Evidence
Allow users to inspect supporting references.

### 5. Safety
Keep responsible-use information visible.

## UX principles

- Do not overwhelm the user with raw technical scores.
- Show "why this result" information.
- Make source/provenance discoverable.
- Clearly distinguish informational content from clinical advice.

## Demo priority

The main path should require as few clicks as possible:
search → results → explanation → evidence.
