# Limitations

## Current prototype limitations

The hackathon version may be constrained by:
- limited seed data
- incomplete terminology coverage
- limited evidence coverage
- small evaluation set
- prototype ranking weights
- limited production infrastructure

## Responsible interpretation

A successful demo should not hide these limitations. Instead, explain how the architecture allows future expansion.

## Future work

- larger curated knowledge base
- stronger terminology mapping
- improved retrieval evaluation
- richer provenance
- more comprehensive safety rules
- scalable data ingestion
- model-assisted extraction with human validation
