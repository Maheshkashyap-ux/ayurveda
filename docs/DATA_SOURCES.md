# Data Sources and Provenance

## Source strategy

Use sources that the team is legally permitted to use and that can be traced to a recognizable origin.

## Source categories

1. Traditional / classical references where permitted.
2. Public research literature.
3. Curated structured datasets.
4. Manually reviewed seed records.
5. Team-created mappings for normalization.

## Provenance requirements

For each source, record:
- source name
- URL or bibliographic identifier where applicable
- access date
- license / usage condition
- data extraction method
- transformation performed
- validation status

## Important rule

Do not silently combine unverified claims with verified source material. Records should be marked according to their evidence/provenance status.
