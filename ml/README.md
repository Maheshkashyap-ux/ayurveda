# Machine Learning / NLP

This folder is reserved for the future NLP and machine learning
components of the Ayurveda Formulation Intelligence System.

## Planned Components

### 1. Text Processing
Process and normalize user-entered disease and symptom descriptions.

### 2. Synonym Resolution
Identify alternative names and terminology used for diseases,
symptoms and medicinal substances.

### 3. Entity Identification
Identify important entities from user input, such as:

- Diseases
- Symptoms
- Drugs
- Formulations

### 4. Context-Aware Matching
Use the context of the user's input to improve identification and
retrieval of relevant Ayurvedic information.

### 5. Recommendation Support
Future NLP/ML components may assist the recommendation engine in
finding and ranking relevant formulations.

## Current Status

No machine learning model has been implemented yet.

The current project uses a basic structured data approach to establish
the initial system architecture.

ML/NLP components will be added during later development stages.
